LATIN WORLD - Actualización PWA para Android 17 / One UI 9 e iOS 27

1. Extrae el ZIP.
2. Sube el CONTENIDO de esta carpeta a la raíz del repositorio GitHub Pages (no el ZIP).
3. Comprueba que index.html, manifest.webmanifest, service-worker.js y la carpeta icons estén al mismo nivel.
4. Usa HTTPS, obligatorio para instalar y habilitar almacenamiento sin conexión.
5. Android: abre la URL en Chrome y elige «Instalar aplicación» o «Añadir a pantalla de inicio».
6. iPhone: abre la URL en Safari > Compartir > «Añadir a pantalla de inicio».
7. Si se muestra el icono antiguo, elimina el acceso directo anterior y añádelo de nuevo.
8. Los datos guardados por el navegador pueden perderse si se borra el almacenamiento del sitio.

La aplicación es una PWA, no un APK/AAB nativo y no requiere targetSdkVersion.
Conserva tasas manuales, margen restado, límite de 3 decimales e historial local.
